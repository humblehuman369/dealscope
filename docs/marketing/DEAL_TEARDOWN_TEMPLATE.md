# Deal teardown template ("Four Paths Friday")

400–600 words. Pick a **public** listing. Run the verdict. Screenshot the
verdict card and the Four Paths. Anonymize the street number unless the
listing is already public. Label every figure as **this listing's numbers**,
not market stats. No advice language. Sign-off: `Google Deal Gap IQ. Know
what to offer.`

---

## Outline

1. **The listing** — city, beds/baths, asking price. One sentence on why it
   looks dead at the ask.
2. **The three numbers** — Income Value, Target Buy, Deal Gap. Cite the
   sources on the card. If a source is missing, write Unavailable. Never
   fabricate.
3. **The gap** — one sentence: the gap is the negotiation.
4. **Which path closes** — pick one of the four. Show the ask in dollars.
   One line on why the other three do not close this listing.
5. **What to say** — two or three lines from the playbook, not a full script
   dump. CTA: run the same address at dealgapiq.com.
6. **Sign-off** and guarantee line.

---

## 45-second screen-recording spec (Shorts / Reels)

Founder records. Agent does not.

| Second | Beat |
|---|---|
| 0–2 | Address typed into the box |
| 2–6 | Verdict card lands; Deal Gap called out |
| 6–20 | Four Paths panel; featured path highlighted |
| 20–40 | One ask spoken in dollars + the opener line |
| 40–45 | End card: `Free verdict. No signup. No card.` then `Google Deal Gap IQ. Know what to offer.` |
