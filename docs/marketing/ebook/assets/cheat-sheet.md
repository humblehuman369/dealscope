# The Deal Gap — One-Page Cheat Sheet

> How far is the asking price from the price where this deal actually works for me?

Printable HTML version: [cheat-sheet.html](./cheat-sheet.html)

---

## Formulas

```
Target Buy ≈ Income Value × (1 − buy discount %)
Deal Gap % = (Asking Price − Target Buy) / Asking Price × 100
```

| Number | Meaning |
|---|---|
| **Income Value** | Ceiling where income stops supporting the deal |
| **Target Buy** | Offer anchor & walk-away (Income Value after your margin) |
| **Deal Gap (+)** | Asking above Target Buy — need concession or structure |

---

## Gap bands (effort)

| Band | Read |
|---|---|
| **0–5%** | Close — negotiate / small tweak |
| **5–15%** | Real work — use Four Paths |
| **15%+** | Hard mode — path, new strategy, or pass |

---

## Four Paths

1. **Price** — negotiate toward Target Buy  
2. **Capital** — improve the stack (not fantasy leverage)  
3. **Income** — re-verify rent, tax, insurance  
4. **Structure** — seller carry, credits, creative finance  

*The price tag isn’t the deal. The structure is.*

---

## Weekly routine

1. Collect address + ask  
2. Defendable rent & expenses (mark unknowns)  
3. Income Value → Target Buy → Deal Gap  
4. Rank strategies that fit you  
5. Choose path(s) — or pass  
6. Log one line  

---

## Anti-phantom checklist

- [ ] Rent defendable (comps / sources)  
- [ ] Tax & insurance are real quotes  
- [ ] Buy discount chosen on purpose  
- [ ] Path named — or explicitly passing
