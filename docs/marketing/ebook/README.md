## Deal Gap definition (authoritative for this book)

```
Deal Gap % = (Asking Price − Target Buy) / Asking Price × 100
```

- **Positive** = asking is above Target Buy — you need that % concession (or structure) for the deal to work.
- **Near zero / negative** = rare; worth a closer look at asking.

Aligned with product methodology (`FORMULA_INVENTORY.md` / `/methodology`), not looser marketing sign flips.
