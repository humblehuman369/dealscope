## Human read (with pause marks)

### [0:00 – 0:45] Hook + promise
*Visual: Homepage; flash address / map / scan.*

> Listing sites end at **price**. /
> Investor calculators end at **cash flow**. //
> Neither tells you *how to close* a deal that doesn’t pencil at asking. //
> That’s where most tools stop. /
> **DealGapIQ keeps going.** //
> Paste any US address. /
> Search on the map. /
> Or use your phone to **scan**. //
> No signup. No credit card. //
> In about fifteen seconds you get a multi-source verdict, /
> six strategies ranked side by side, /
> and — when the numbers are tight — **four ways to structure the offer**, /
> with a negotiation script for each.

---

### [0:45 – 1:15] Analyze
*Visual: Address submit → analyzing → discovery loading.*

> I’m going to run a real property. /
> Behind the scenes we’re pulling live data — /
> Zillow, RentCast, Redfin, Realtor.com — /
> and blending what we can into an **IQ Estimate**. //
> If a source is missing, we show **Unavailable**. /
> We never invent a number.

---

### [1:15 – 2:00] Verdict
*Visual: Target Buy / Income Value / Market Price / Deal Gap.*

> This is your **Verdict**. //
> Three numbers say it all. /
> **Target Buy** — the price that hits your return thresholds. /
> **Income Value** — the max you can pay and still cash-flow positive. /
> **Market Price** — what the seller wants. //
> The **Deal Gap** between them is the focus. /
> Walk away. Negotiate. Or write the offer. /
> **We show you options.**

---

### [2:00 – 2:40] Trust + strategies
*Visual: IQ selector briefly; six strategy snapshots.*

> Every metric shows its source. /
> Switch the estimate — watch the math change. //
> Nothing here is a black box. //
> Same property — **six** ways to profit. /
> Long-term rental. Short-term. BRRRR. Flip. House hack. Wholesale. //
> Ranked so you see which strategy fits *this* asset — /
> without six separate spreadsheets.

---

### [2:40 – 3:40] Four Paths
*Visual: Four Paths panel + Blended Plan.*

> Here’s the part most tools never reach. //
> A negative gap isn’t a dead deal. /
> It’s a **structure** problem. //
> DealGapIQ builds four paths to close the gap: /
> a price ask, /
> a capital ask, /
> financing — Subject-To, seller carry, creative structures — /
> income re-verification, /
> and a **Blended Plan** that combines smaller asks into one credible package. //
> A six-percent price cut can be a no. /
> Two percent plus seller carry plus verified rent / can be the same math — and a yes.

---

### [3:40 – 4:30] Pitch script
*Visual: Pitch Script modal — copy / email / print.*

> And we don’t stop at the spreadsheet. //
> For each path you get a **pitch script**: /
> who to call, /
> how to frame it, /
> the opener, /
> the ask, /
> and what’s in it for the seller. //
> Print it. Email it. Copy it to your phone before you dial. //
> From “does it pencil?” / to “how do I actually get this under contract?”

---

### [4:30 – 5:20] Deal Maker
*Visual: Deal Maker sliders; metrics recalc.*

> **Deal Maker** is the interactive worksheet. /
> Change purchase price. Down payment. Rent. Loan type. //
> Every metric recalculates live — /
> and it stays consistent with the Verdict you just saw. //
> Same math. Same record. /
> When you’re ready for a lender, export to Excel.

---

### [5:20 – 6:00] Map tease + close
*Visual: Map Search pins; logo + dealgapiq.com.*

> Don’t have an address yet? /
> **Hunt the whole market.** //
> Map Search pre-grades parcels — /
> with foreclosure, pre-foreclosure, and auction filters. /
> Beyond the MLS. //
> DealGapIQ isn’t a listing site. /
> It’s a **deal decision engine**. //
> Start free — ten analyses a month, no credit card. /
> Go Pro when you want the full workbench. //
> **The price tag isn’t the deal.** /
> **The structure is.** //
> We analyze. /
> You decide. //
> **DealGapIQ.com**
